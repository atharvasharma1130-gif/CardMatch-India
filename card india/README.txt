# 💳 CardMatch India

An interactive, responsive fintech web application built to help Indian consumers navigate credit cards and find the best matches based on their lifestyle, spending habits, and reward preferences.

## 🚀 About the Project
Navigating credit card rewards, annual fees, and UPI benefits in India can be overwhelmingly complex. As a student, I wanted to build a clean, lightning-fast digital solution that simplifies financial decision-making. 

**CardMatch India** guides users through a quick 5-step interactive quiz and processes their inputs through a custom recommendation engine to instantly match them with top-tier Indian credit cards (such as the SBI Cashback, Amazon Pay ICICI, and HDFC Tata Neu cards).

## 🛠️ Features
- **5-Step Interactive Quiz:** Dynamic questionnaire covering primary spending categories, reward types, annual fee tolerances, monthly budgets, and UPI/RuPay requirements.
- **Smart Matching Engine:** Calculates compatibility scores to recommend the best card options alongside secondary alternatives.
- **Modern UI/UX:** Styled with a sleek, minimalist fintech aesthetic inspired by modern financial platforms.
- **Responsive Design:** Fully optimized for seamless use across both mobile and desktop screens.

## 💻 Tech Stack
- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
